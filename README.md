# HCL Mainframe Training - Practice Programs

Mainframe interview preparation practice programs I am building for my HCL Mainframe Training.

## Practice Priority Order

| Priority | Subject | Focus |
|----------|---------|-------|
| 1 | COBOL | Program structure, conditions, loops, files, tables, CALL |
| 2 | DB2 + SQL | SQL queries, joins, cursors, SQLCODE, embedded SQL |
| 3 | JCL | JOB, EXEC, DD, DISP, utilities, PROC |
| 4 | VSAM + GDG | Dataset types, IDCAMS, GDG generations |
| 5 | Mainframe + TSO/ISPF | Architecture, dataset and job management |
| 6 | DB2 advanced | Performance, concurrency, bind options, LUW |
| 7 | Capstone | Project explanation and troubleshooting |
